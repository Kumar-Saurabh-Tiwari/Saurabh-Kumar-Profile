# Saurabh Kumar

Portfolio for Saurabh Kumar, a full stack developer. Live site: [skumar.space](https://skumar.space).

Built with Remix, Three.js, and Framer Motion. The contact form opens a message to [hello@skumar.space](mailto:hello@skumar.space).

- **Skills:** React, Next.js, Angular, Node.js, databases, AI tools (OpenAI, Groq, Ollama, Claude, Gemini, Cursor, Copilot, Perplexity), and AWS / Azure
- **Certificates:** NIIT StackRoute, Meta Front-End, Generative AI, Microsoft Azure, AWS Cloud Practitioner, and Remasto
- **Contact:** hello@skumar.space, GitHub, LinkedIn, X, and Instagram

## Run locally

Node `19.9.0` or newer.

```bash
npm install
npm run dev
```

The dev server runs at [http://localhost:7777](http://localhost:7777).

## Deploy

The production build is for Vercel. Set the project root to this folder, the framework to Remix, and the build command to:

```bash
npm run build
```
